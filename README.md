# Blood-donation-app-
जीवनदान एक सरल और उपयोगी Blood Donation App है, जिसका उद्देश्य रक्तदाताओं और जरूरतमंद मरीजों को एक ही प्लेटफ़ॉर्म पर जोड़ना है। इस ऐप के माध्यम से उपयोगकर्ता आसानी से रक्तदाताओं को खोज सकते हैं, रक्त की आवश्यकता पोस्ट कर सकते हैं और आपातकालीन परिस्थितियों में तुरंत सहायता प्राप्त कर सकते हैं।
